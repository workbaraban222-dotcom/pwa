ТЕСТОВЫЙ PWA-ЛЕНДИНГ

Публикация:
1. Распакуйте архив.
2. Загрузите содержимое папки pwa-test-landing в Netlify Drop: https://app.netlify.com/drop
   (можно перетащить всю папку; если не принимает папку — загрузите ZIP).
3. Получите публичную HTTPS-ссылку.
4. Откройте ссылку в Chrome на Android. Дождитесь загрузки страницы.
5. Нажмите «Установить приложение». Если событие установки не появилось, откройте меню Chrome ⋮ и выберите «Установить приложение» / «Добавить на главный экран».

ВАЖНО:
- Для PWA обязателен HTTPS (кроме localhost).
- Кнопка вызывает системный диалог, когда браузер сообщает, что установка доступна.
- Встроенный браузер Facebook может не поддерживать установку PWA. Для теста откройте меню Facebook и выберите «Открыть во внешнем браузере», затем Chrome.
- Не очищайте данные сайта, если хотите проверить повторный запуск в установленном режиме.
